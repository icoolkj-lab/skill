# Skill Library

A collected library of AI Agent Skills, including standalone skills, suites, sub-skills, scripts, references, and assets. **Collection does not imply verification, safety, commercial permission, or redistribution rights.**

## Start here

- [Skill directory index](skills/INDEX.md) — browse entrypoints by use case.
- [Local curated skills data](data/local_skills.json)
- [Online skill search](https://skill.miyucaicai.cn/skills.html)
- [Asset catalog and governance](catalog/README.md)
- [Curated catalog page](docs/catalog/local-skills.md)

## Repository layout

| Directory | Purpose |
|---|---|
| skills/ | Collected skills, suites, and sub-skills |
| my-skills/ | Custom/local skills |
| finance-skills/ | Finance-related collection |
| projects/ | Standalone projects and applications |
| antinet-agentteams/ | Agent-team project and supporting skills |
| catalog/ | Asset registry, categories, relations, and schemas |
| data/, public/data/ | Collection and website data |
| scripts/, tools/ | Sync, validation, and maintenance utilities |
| docs/ | Documentation and historical materials |
| templates/ | Skill authoring templates |

## Use

1. Browse the index.
2. Read the skill's SKILL.md for usage and limitations.
3. Inspect scripts, references, dependencies, source, and licensing before use.

See contributing, asset governance, and directory conventions linked from the Chinese README.
