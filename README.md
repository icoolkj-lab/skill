# Skill 技能资源库

集中收集、整理、检索和管理 AI Agent Skills。这里包含精选技能、完整上游套件、子技能、脚本、参考文档和资源；**收录不代表已验证、安全、可商用或拥有再分发授权**。

## 快速入口

- **[技能导航索引](skills/INDEX.md)**：按用途浏览本地 Skill 入口。
- [本地精选技能数据](data/local_skills.json)
- [在线技能检索](https://skill.miyucaicai.cn/skills.html)
- [资产目录与治理](catalog/README.md)
- [本地精选目录](docs/catalog/local-skills.md)

## 仓库结构

| 目录 | 用途 |
|---|---|
| skills/ | 收录技能、套件与子技能；从导航索引进入 |
| my-skills/ | 自建/本地技能资产 |
| finance-skills/ | 金融领域技能集合 |
| projects/ | 独立项目与应用，不混作普通 Skill |
| antinet-agentteams/ | Agent 团队项目与配套 Skill |
| catalog/ | 资产登记、分类、关系与 Schema |
| data/、public/data/ | 本地集合数据与网站索引 |
| scripts/、tools/ | 同步、校验和维护工具 |
| docs/ | 使用说明、治理规范与历史资料 |
| templates/ | Skill 创建模板 |

## 使用建议

1. 从[技能导航](skills/INDEX.md)按场景找技能。
2. 阅读对应 SKILL.md，确认适用场景、步骤和限制。
3. 使用前检查来源、许可证、依赖、网络调用及文件操作。
